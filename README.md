# GRSAI NewAPI

OpenAI-compatible API adapter for GRS AI chat and image models.

## API service

```bash
GRSAI_API_KEY=sk-your-key go run .
```

Default server:

```text
http://localhost:8080
```

## Documentation

```bash
npm install
npm run docs:dev
```

Build static docs:

```bash
npm run docs:build
```
